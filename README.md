# FORGE

Capture the idea. Test its potential. Make it real.

A native iOS app (SwiftUI, SwiftData, iOS 17+) for one person to capture ideas,
pressure-test them against named frameworks, and turn the worthwhile ones into projects.

- `docs/FORGE_BRIEF.md` is the source of truth for product and architecture.
- `docs/00-first-deliverable.md` is the pre-code deliverable from §13 of the brief:
  open decisions, the Phase 0 file tree, and the Lens A / A2 teaching content.

Phase 0 (scaffold) starts once the first deliverable is approved.
